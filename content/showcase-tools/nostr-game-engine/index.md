Nostr Game Engine is a jMonkeyEngine-based engine for building games and applications that integrate with the Nostr ecosystem. 

It focuses on social features, decentralized matchmaking, peer-to-peer networking, and player identity without a central authority or server. 

Nostr Game Engine (NGE) is designed to be modular, extensible, and cross-platform. It can deploy to a wide range of platforms, including web browsers.
