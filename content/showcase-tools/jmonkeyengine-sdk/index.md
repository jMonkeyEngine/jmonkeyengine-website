The jMonkeyEngine SDK, now turned into a community project, is the original NetBeans-based development environment that was developed for jMonkeyEngine 3. It provides project templates, scene tooling, asset workflow helpers, and editor integrations.

While nowadays JME is a code-first engine, the SDK still serves as a useful starting point for new users that want a more integrated experience.
