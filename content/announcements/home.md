jMonkeyEngine 3.10 is now in beta! This release rewrites the platform backends from the ground up, improves iOS support, adds better compatibility and DPI handling, refreshes input support, improves lighting and PBR behavior, fixes shader issues, improves glTF support, and much more. 

Read the [3.10 beta forum thread](https://hub.jmonkeyengine.org/t/jme-3-10-0-beta1/49603) for install snippets and discussions.
