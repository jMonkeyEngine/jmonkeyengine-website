Engines, editors & tools

6 jMonkeyEngine based engines, editors, and practical production tools from the ecosystem.

Engine

Exotic Matter Engine

A custom voxel/sandbox engine and technology stack built around jMonkeyEngine for the Exotic Matter project.
Tool

SceneMax3D

A desktop-based game development environment designed around a visual workflow and a custom scripting language.
Editor

jMonkeyEngine SDK

NetBeans-based development environment for jMonkeyEngine projects: templates, scene tooling, asset workflow helpers, and desktop project setup.
Tool

EnvisionPlay

EnvisionPlay is a visual game editor designed to make creating 2D and 3D games simple and accessible. It provides an intuitive workflow that allows developers to focus on building gameplay instead of writing boilerplate code.
Editor

Maud

A dedicated editor for jMonkeyEngine 3D models, focused on inspecting and editing assets outside the game runtime.
Engine

Nostr Game Engine

A game engine and framework for building games and applications integrated with the Nostr ecosystem.

The modern game engine for Java developers. Open source, BSD-3 licensed, since 2004.
